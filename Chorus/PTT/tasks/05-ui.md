# Task 05 — SwiftUI views: Settings tab and Edit Service picker

## Goal
Write the two SwiftUI views the app already references (hooks are in place):
1. `PTTLinkSettingsTab` — a Settings tab, used in `SettingsView` as `PTTLinkSettingsTab()` inside a `TabView`. It must apply its own `.tabItem { Label("Links", systemImage: "arrow.up.right.square") }`. The Settings window is 520×460 pt, so the content scrolls (`Form` with `.formStyle(.grouped)`, like the other tabs in `Chorus/Views/Settings/SettingsView.swift`).
2. `PTTServiceProfilePicker(serviceID: UUID)` — one row inside the Edit Service sheet (`Chorus/Views/AddService/EditServiceSheet.swift`, right after the "Open outside links in" picker; look at it for style). A `Picker("Chrome profile", selection:)` with "None" (nil) and one option per Chrome profile, plus a `.help(...)` text. It saves immediately on change through `PTTLinkService.shared.setServiceProfile(_:for:)` and reads the initial value with `serviceProfile(for:)`. If the saved name is not among the profiles, still show it as an option marked "(not found)".

## Files you may edit
- `Chorus/PTT/UI/PTTLinkSettingsTab.swift` (new)
- `Chorus/PTT/UI/PTTServiceProfilePicker.swift` (new)
- `Chorus/PTT/UI/PTTRuleRow.swift` (new, optional, for the rule editor row)

Do NOT edit anything else (not `PTTLinkService`, not author files).

## API to use (read these files first)
- `Chorus/PTT/App/PTTLinkService.swift`: `@MainActor @Observable final class PTTLinkService`, `static let shared`. Properties: `rules: PTTRuleSet`, `ruleFileError: String?`, `profiles: [PTTChromeProfile]`, `log: PTTLinkLog` (`entries`, newest first), `ruleFileURL`. Methods: `reloadRules()`, `reloadRulesIfChanged()`, `saveRules(_:)`, `revealRuleFile()`, `reloadProfiles()`, `serviceProfile(for:)`, `setServiceProfile(_:for:)`, `resolve(_ url:, serviceProfile:, ownedByChorus:) -> PTTLinkResolution`.
- `Chorus/PTT/Core/PTTLinkRule.swift` (`PTTLinkRule`, `.Kind`, `isValid`, `PTTRuleSet`), `Chorus/PTT/Core/PTTLinkResolver.swift` (`PTTLinkResolution` with `branch`, `target`, `url`, `profileName`), `Chorus/PTT/Core/PTTChromeProfiles.swift`.
- Hold the service as `@State private var links = PTTLinkService.shared` (Observation; macOS 14).

## Settings tab content (sections, in order)
1. **Rules** — a `List`/`ForEach` of rules in order, each row: kind picker (Domain / Wildcard / Regex), pattern `TextField`, profile picker (Chrome profile names; keep an unknown saved name visible), a red warning icon with `.help` when `!rule.isValid` or the profile is not found, and a delete button. Reorder by drag (`.onMove`). An "Add Rule" button appends a domain rule with an empty pattern and the first profile name (or "" if none). Every edit calls `links.saveRules(...)` with the whole updated `PTTRuleSet`. Footer text: rules are checked top to bottom; the first match wins; they win over a service's own profile.
2. **Rule file** — the file path (`.textSelection(.enabled)`, caption font), buttons "Reveal in Finder" (`revealRuleFile()`) and "Reload" (`reloadRules()` and `reloadProfiles()`), and `ruleFileError` in red when set.
3. **Test a link** — a `TextField` for a URL and a picker "As if clicked in a service using" (None + profile names). Show the result live: unwrapped URL, which branch ("Rule: domain youtube.com", "Service profile", "No rule — Chorus decides"), and the profile that would open (or "Profile not found: X").
4. **Recent links** — `links.log.entries` (max 20, in memory only): time (`.formatted(date: .omitted, time: .standard)`), URL (one line, truncated middle), source service, rule, profile. Empty state text "No links opened yet."
5. **Chrome profiles** — read-only list of `profiles` (name, email, directory), and a note when empty: "Chrome's Local State was not found or could not be read."

## Style rules
- English UI text, short and plain. Follow `CLAUDE.md`: keep each `body` short — split sections into private computed properties or small private structs; no long modifier chains (an old CI compiler times out on long bodies).
- Swift 6 strict concurrency, macOS 14 APIs only (no macOS 15+ only modifiers without `#available`).
- Must compile with Xcode 16.2 (see `CONTRIBUTING.md` "Build and test" list of pitfalls: e.g. no private stored property in a View that another file constructs with a memberwise init — give `PTTServiceProfilePicker` an explicit `init(serviceID:)`).
